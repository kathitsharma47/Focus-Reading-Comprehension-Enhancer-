# ⚡ FocusRead: Algorithmic Study Enhancer

A cognitive reading and study-acceleration tool built entirely in Python and Streamlit. It uses algorithmic string parsing to generate Bionic Typography fixation points, guiding saccadic eye movements to enhance reading pace and retention for academic texts.

---Key Highlights
- Algorithmic Fixation Points:Transforms natural language strings by isolating and emphasizing word-initial phonemes.
- Reading Telemetry Engine: Computes real-time word distributions, character densities, and estimated cognitive processing duration.
- WPM Diagnostics: Includes an interactive benchmarking timer to evaluate user reading velocity before and after typographical formatting.
